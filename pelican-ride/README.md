# 鹈鹕骑行 · 加州 1 号公路

一只戴着墨镜、围着红围巾的褐鹈鹕,骑着自行车(车筐里还有两条鱼)沿加州西海岸的太平洋海岸公路(PCH / Highway 1)一路向南 —— 从旧金山金门大桥,经鸽子角灯塔、大瑟尔的比克斯比溪大桥、莫罗岩,一直骑到圣莫尼卡码头和马里布。纯 three.js,**全部场景与贴图都是程序化生成**,没有任何外部模型 / 图片资源。

直接打开 [`index.html`](./index.html) 即可(单文件,three.js 与代码已内联,可离线使用)。

## 光影

- **真实的太阳**:按纬度 36.5°、8 月初计算太阳高度角/方位角。太阳在西边的海面上落下,鹈鹕向南骑行,夕阳始终在右手边。时间默认随旅程从午后推进到日落,也可以用滑条自由拖动(5:30–19:15)。
- **大气散射天空**(Preetham)+ 实时生成的 **IBL 环境光**(PMREM):天空颜色、地面反射、金属/清漆高光都随时间变化。
- **ACES 电影级色调映射 + 自动曝光**,黄昏时自动补偿;**Bloom** 产生太阳光晕与海面闪光。
- **阴影**:跟随鹈鹕的方向光阴影(texel 对齐防闪烁,PCF 软阴影),树木、护栏、桥梁、鹈鹕与车的影子随太阳角度拉长;远处山体/悬崖的自遮挡阴影按太阳方向烘焙进地形顶点。
- **大气雾**:指数雾 + 朝太阳方向的前向散射色;金门大桥与大瑟尔一带海雾更浓。
- **海面**:程序化多层波浪法线、菲涅尔反射、逆光时浪尖的青绿色次表面散射、近岸半透明浅滩与岸边泡沫。
- **夜幕将至**:路灯、车灯/尾灯、摩天轮彩灯、码头招牌、鸽子角灯塔的旋转光束会随暮色亮起。

## 沿途

金门大桥 → 太平洋城/魔鬼滑坡 → 鸽子角灯塔 → 半月湾 → 大瑟尔与**比克斯比溪大桥** → 莫罗湾**莫罗岩** → 圣巴巴拉海岸(救生塔、棕榈大道)→ **圣莫尼卡码头**(会转动的摩天轮)→ 威尼斯海滩 → 马里布。底部进度条上的圆点可以直接跳转。

沿路有柏树、红杉/松树、橡树、棕榈、灌木、冰花(粉红色)、岩石、海蚀柱,以及盘旋的海鸥和一队 V 字编队飞行的褐鹈鹕。

## 开发

```bash
cd pelican-ride
npm install        # three + esbuild
npm run build      # 生成单文件 index.html
npm run dev        # 监听源码变更并重新生成
```

调试参数(URL query):`?s=3800`(起始里程,米)、`?t=18.5`(固定时刻)、`?cam=side`(初始视角)、`?q=low|medium|high`(画质)、`?v=10`(速度,m/s)、`?pause=1`、`?hide=1`。

### 设计要点

- **路线带状坐标**:世界由 `(s, d)`(沿路里程、横向偏移,d>0 为海侧)参数化;地形、植被、地标都用同一个高度函数 `terrainHeight(s, d)` 生成,因此彼此严丝合缝。路线曲率受限(最小转弯半径约 450 m),带状网格不会折叠。
- **远景地形**用世界坐标网格,通过预计算的最近路线点网格把任意世界点投影回 `(s, d)`,与带状地形共用同一函数,中间挖洞避免重叠。
- **深度精度**:`logarithmicDepthBuffer`,近处 3 cm 的鹈鹕喙与 20 km 外的海平线共存。
- **性能**:动态分辨率(自动档)、仅近处植被参与阴影、实例化渲染、地形分块复用缓冲区。
